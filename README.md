# Planche Photo ID

Application web gratuite permettant de recadrer une ou plusieurs photos d’identité, de remplir automatiquement une feuille et de télécharger un PDF aux dimensions exactes, prêt à imprimer.

## Principes

- traitement entièrement local dans le navigateur ;
- aucune photo envoyée sur un serveur ;
- cadrage tactile ou à la souris, avec zoom et guides visuels ;
- formats photo français 35 × 45 mm, américain 51 × 51 mm et personnalisés ;
- papiers A4, A5, A6, 10 × 15 cm et personnalisés ;
- remplissage automatique alterné ou groupé par photo d’origine, marges, espacement et traits de découpe ;
- PDF généré directement dans le navigateur ;
- application installable et utilisable hors connexion après la première visite.

## Utilisation locale

Servez le dossier `dist` avec n’importe quel serveur HTTP statique, puis ouvrez l’adresse indiquée dans votre navigateur.

## Avertissement administratif

L’application aide à respecter les dimensions et le cadrage, mais ne délivre aucune certification. Pour une carte nationale d’identité ou un passeport français, la photographie doit être réalisée par un professionnel habilité ou dans une cabine agréée.
